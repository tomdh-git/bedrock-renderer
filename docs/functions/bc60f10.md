### Purpose

Copies the encoder's optional per-draw side table into the Frame for draw `idx`. The side table holds, for each of the 65 binding stages, a variable-length array of 0x14-byte bindings: this is the storage behind "ranged"/multi binds (more than one resource bound to a stage for one draw), which the fixed 65-entry RenderBind cannot hold [V layout, [I] the "ranged bind" name]. Called from the four submit forms when `Encoder+0x680` is non-null [V]. Instruction-complete below.
