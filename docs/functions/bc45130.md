**Range:** [0xbc45130, 0xbc45291)  (0xbc45290 = `int3` dead padding after the noreturn call; last instruction inside the extent)

**Signature:** `native::bgfx::FbSsoString* sub_bc45130(FbSsoString* dst = rcx, const FbSsoString* src = rdx) -> FbSsoString*` (rax = rcx = dst at `ret`; exact x64 Microsoft ABI)

## Register / argument map

- `rcx` = `dst` (destination small-string object); copied nowhere else, returned in `rax`
- `rdx` = `src` (source small-string object, read only); saved in `r15` across the allocator call
- `rsi` = size working copy (loaded from `src+0x28`)
- `rdi` = `srcData` (`&src+0x18` inline base when small, else `src->mData` heap pointer)
- `r12` = capacity (heap size class)
- `r14` = saved `dst` across the allocator call (`[rbp-0x10]` slot)
- `r15` = saved `src` across the allocator call
- `rax` = scratch / allocation result / return value
- Stack: `rbp = rsp+0x30` frame; cookie slot `[rbp-8] = 0xFFFFFFFFFFFFFFFE` (written, never read); dst save slot `[rbp-0x10]`

## Ownership / threading

Single-threaded frame-builder string copy. Reads `src` (read-only object), writes `dst`, returns `dst`. Allocation through the imported CRT allocator (`std::malloc`); on allocation failure or negative size a noreturn CRT handler runs. No cross-thread effects, no GPU visibility.
