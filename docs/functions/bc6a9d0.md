### Purpose

bgfx `rendererUpdateUniforms`: replays one draw's range `[begin, end)` of the Frame's uniform buffer (the values the game set with setUniform before submitting) into the renderer's per-handle uniform storage, so that the constant commit (0xe81e1c0) can then copy them into each shader's constant buffer. Mojang addition: it also records every uniform handle it touched, sorted and unique, in a vector the caller passes. Called from the executor's draw path when the program or the uniform range changed (0xe82a1f6) [V]. All 143 instructions are accounted for below, together with the two renderer virtuals it calls.
