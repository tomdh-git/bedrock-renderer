## Phase notes

- `0xe8141e0..0xe814206`: prologue; compute `entry = ctx + idx*0xB8 + 0xAAA178`; load
  `release = entry->p8`. If `release == 0`, skip the first release and the `p8` clear.
- `0xe814208..0xe814238`: release `release` through `g->vtbl[1]` (g = `*[0x12ADF800]`),
  then null `entry->p8`. If `g == 0` the call is skipped but `entry->p8` is still nulled.
- `0xe814240..0xe814261`: clear flag byte `entry+0xB0`; load `rsi = entry->p0`. If `rsi!=0`
  and `[rsi] != rsi+0x10` and `[rsi+0x10] != 0`, fall through to the inner release.
- `0xe814263..0xe814267`: inner release through `[rsi+0x10]` with `rcx=[rsi]`, `rdx=[rsi+0x18]`.
- `0xe81426d..0xe81429a`: release `rsi` through `g->vtbl[1]` (g = `*[0x12ADF800]`).
- `0xe8142a0..0xe8142a7`: null `entry->p0`; clear the dword at `entry+0xA8`.
- `0xe8142b1..0xe8142b7`: epilogue.
