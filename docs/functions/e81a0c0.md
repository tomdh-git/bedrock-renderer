## Data slots / callees

- `[0x12ADF800]` = global allocator interface pointer `g` (read-only slot).
- `[0xF99FFA0]` = `sub_eea6040` (`jmp rax`), loader-resolved CFG dispatch thunk — class `vendor`
  (`docs/data/native_boundary.tsv` line `0xeea6040 vendor thunk via data slot 0xF99FFA0 (loader-resolved)`).

- Allocator method `g->vtable[1]` is a unified `reallocate(self, ptr, size, 0, 0, 0)`:

## Phase-by-phase

### 0xe81a0c0..0xe81a0f8 — prologue + vecA destructor pass
Push rsi/rdi/rbp/rbx; `sub rsp,0x38`; `rsi=this`. `rdx=this->vecA_first`; `rdi=*rdx` (list head);
if head==0 jump `0xe81a16d`. Loop over the intrusive list (next at node+0x10): `obj=node->[8]`,
call `obj->vtable[2](obj)`, `node=node->[0x10]`.

### 0xe81a0fa..0xe81a120 — vecA free pass setup
`rdx=this->vecA_first`; `r8=*rdx` (head); `rcx=g`; if head==0 jump `0xe81a174`; else `rdx=head`, jump into the free loop.

### 0xe81a120..0xe81a16b — vecA free pass
For each node: `next=node->[0x10]`; if `g` { `free(node)` via `g->vtable[1]`; reload `g` }; advance. On `next==0`, `rdx=this->vecA_first`, fall to `0xe81a174`.

### 0xe81a16d..0xe81a2e2 — vecA buffer reset + state40
`0xe81a16d`: `rcx=g` (head was null). `0xe81a174`: `this->vecA_last=this->vecA_first`.
If `vecA_first+0x48 <= this->vecA_end` reuse buffer (`buf=vecA_first`); else allocate 0x48, copy
`[first,last)` (empty), free old buffer, `vecA_first=buf`, `vecA_end=buf+0x48`. Zero buf `[0,0x48)`.
`this->vecA_last=this->vecA_first+0x48`; `this->state40=0`.

### 0xe81a2d6..0xe81a347 — vecB free pass
`rdx=this->vecB_first`; `r8=*rdx` (head); `r8=g`; walk the list (next at +0x10) freeing each node and reloading `g`.

### 0xe81a34b..0xe81a4b2 — vecB buffer reset + state60
`this->vecB_last=this->vecB_first`; reuse-or-reallocate to a zeroed 0x48 region (same logic as vecA);
zero buf; `this->vecB_last=this->vecB_first+0x48`; `this->state60=0`.

### 0xe81a4a2..0xe81a536 — index buffer free + allocate
`rdx=this->p08`; `count=((uint16_t*)p08)[1]` (zero-extended). If `g`: `free(p08)`; reload `g`;
if `g`: `buf=allocate(count*4+4)` else `buf=0`. (If `g`==0 at entry, `buf=0`.)

### 0xe81a52a..0xe81a5fd — identity index fill + store
`((uint16_t*)buf)[0]=0`; `((uint16_t*)buf)[1]=count`; if `count!=0`, fill body `((uint16_t*)buf)[2+i]=i`
for `i` in `[0,count)`. The original does this with SIMD (`movdqa` from constants `0xF441430=[0..7]`,
`0xF08ED30=[8x8]`, `0xF441630=[16x8]`, `0xF441640=[0,1,2,3]`, `0xF441650=[4,4,4,4]`) plus a 4-wide and a
scalar tail; all produce the same identity sequence. Then `this->p08=buf`; epilogue `add rsp,0x38; pop; ret`.
