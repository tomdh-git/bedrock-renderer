# BgfxFrameBuilder::endFrame — dossier (0xbc40a30, size 0x146)

**Range:** [0xbc40a30, 0xbc40b76)  (0xbc40b75 = `int3` padding; 0xbc40b80 starts a new function outside this range)
**Version:** Minecraft Bedrock 1.26.62.01
**Signature:** `BgfxFrameBuilder* endFrame(BgfxFrameBuilder* dst = rcx, void* src = rdx) -> BgfxFrameBuilder*` (rax = rsi = dst at `ret`)

## Register / argument map

- `rcx` = `dst` (this-pointer / destination BgfxFrameBuilder)
- `rdx` = `src` (source frame data / source BgfxFrameBuilder)
- `rsi` = `dst` (copy of rcx, used for all dst stores)
- `rdi` = `src` (copy of rdx, used for all src loads)
- `rbx` = `size` (loaded from src+0x28)
- `r14` = `srcData` (either `&src+0x18` for SSO or `src->mData` for heap)
- `r12` = `capacity` (size class for heap alloc)
- `r15` = temp: alloc size or heap block base
- RSP-0x28 home space, no stack locals used beyond that
