## Purpose [V]

Render-thread frame lambda ("GraphicsTasks - Render", BGFX_MAP line 567). Runs the render-task loop: begins a trace scope, reads QPC time, computes a timeout, waits on a fence/semaphore (`sub_eec58f0/eec5920/eec5930`), then either executes the pending task directly via `GraphicsTasks Execute` `0xc25fc50` (3 call sites: states 3, 2-matched, 0) or, on state-2 mismatch, allocates a 0xF8 task object, runs constructors `sub_eec5860/eec5870`, performs a virtual release, refcounts/handoffs the task (`[rsi+0x98]`, `[rsi+0xA0]`, `[rsi+0x150]`), signals a counter (`lock xadd [r14+0x90]`), enqueues via `sub_abd50`/`sub_eec5b90`, walks a shared_ptr chain, calls `sub_c266ba0`, and loops. On timer expiry it ends the trace scope ("GraphicsTasks - Render") via `sub_2fe330`/`sub_e935740`/`sub_e938d70` and loops. Null task hits `sub_9bc830` then `int3` (breakpoint).
