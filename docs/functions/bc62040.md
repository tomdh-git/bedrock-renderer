## Reversed source

The function is a six-pass radix counting sort over `n` `(u64 key, u16 word)` pairs. Each pass:
1. `memset(counters[2048], 0, 0x2000)`
2. pairwise count loop binning by the pass digit while tracking a sorted flag `cl = AND(src[i] <= src[i+1])` over all adjacent pairs;
3. if `sorted` -> early exit (data already canonical, no distribute);
4. else group-of-4 exclusive prefix scan over `counters[0..2047]` then pairwise distribute plus an odd tail, writing `(key, word)` to the pass's destination.

Pass digits and directions:
- A: `key & 0x7FF`, keys -> workKeys
- B: `(key >> 9) & 0x1FFC` (byte-offset bins), workKeys -> keys
- C: `(key >> 22) & 0x7FF`, keys -> workKeys
- D: `(key >> 33) & 0x7FF`, workKeys -> keys
- E: `(key >> 44) & 0x7FF`, keys -> workKeys
- F: `key >> 55` (0..0xFF bins, no mask), workKeys -> keys

The count loop itself never moves data (it only bins), so an already-sorted input can exit after counting with data left in place. Where the sorted data resides in `workKeys` (passes B/D/F sorted exits, or pass A/C/E followed by a later pass), a fixup block copies `memcpy(keys, workKeys, count*8)` plus `memcpy(words, workWords, count*2)` before the epilogue.
