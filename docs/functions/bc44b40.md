# sub_bc44b40 — dossier (0xbc44b40, size 0x133)

**Range:** [0xbc44b40, 0xbc44c73)  (0xbc44c72 = `int3` padding inside the range; 0xbc44c80 starts a new function outside this range)
**Version:** Minecraft Bedrock 1.26.62.01
**Signature:** `native::bgfx::FbSlot41Dst* sub_bc44b40(FbSlot41Dst* dst = rcx, uint8_t tag = rdx low byte, const FbSlot41Src* src = r8, void* extra = r9) -> FbSlot41Dst*` (rax = rdi = dst at `ret`)

## Register / argument map

- `rcx` = `dst` (destination object); copied to `rdi`, used for all dst stores
- `rdx` = `tag` (only the low byte `dl` is stored, at dst+0x00)
- `r8` = `src` (source object); copied to `rbx`, used for all src loads
- `r9` = `extra` (pointer); copied to `rsi`, stored at dst+0x48
- `rbx` = `src` working copy
- `r14` = `size` (loaded from src+0x28)
- `r15` = `srcData` (SSO base `&src+0x18` or heap pointer `src->mData`)
- `r12` = `capacity` (heap size class)
- `rax` = scratch / allocation result / return value
- RSP-0x20 home space, no stack locals used beyond that

## Ownership / threading

Single-threaded frame-builder operation; no cross-thread effects. The function reads the source object and writes the destination object (distinct objects); returns the `dst` argument pointer. Allocation goes through the imported CRT allocator; on allocation failure or a negative size a noreturn CRT handler is invoked.
