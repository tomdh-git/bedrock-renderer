### Purpose

`BgfxFrameBuilder_slot16` (0xe878550, size 0x225): builds a FrameBuilderNode tree recursively from an input node structure. Allocates a 0x50-byte output node, copies string data (SSO inline for len<=0x15, heap-allocated for longer), copies scalar fields from input node, then recursively processes left child ([inputNode+0]) and right child ([inputNode+0x10]), linking results into the output node's leftChild/rightChild fields. Returns the output node pointer. [V]
