### Purpose

Earlier notes (6bm) called this the "per-item material resolver". It is a thread-safe, keyed **get-or-load cache** for render resources (materials and the like, by key). Callers: every group visitor case that needs a material (Editor 1-4, BlitFlipbook, HudIcon, UIImGui, Sky 7, the Item visitor's crack/selection overlays), the terrain builder (x5) and others. All 0x4EC bytes read, including the three map helpers 0x567cf50, 0x567d9f0 and the request builder 0x567d050.

### What this means

- Marking a key stale (inserting it into +0x40) is how the game forces a reload (resource-pack change); the old resource is parked in `mRetired` until it is collected.
- The `used` byte at entry+0x30 is the per-frame mark a sweep can use to evict unused entries [I: the sweep is not read].
- A material swap can be done at this level by key: replacing `Holder::resource` for a key changes every draw that resolves it [I].
