## Analyst sections

### Purpose

`sub_6ae330` releases the refcounted objects referenced inside a range of 0x18-byte elements and then clears the 24-byte header at [a0+0x00..0x17]. It walks [a0+0x00, a0+0x08) in steps of 0x18; for each element it releases [elem+0x10] via the eea6040 thunk with flag 1 and lock-dec's the count at [elem+8+0xC], releasing [elem+8] via the eea6040 thunk when the count reaches zero. After the loop it calls sub_e935700 on a derived pointer (start when size < 0x1000, else *(start-8) when that derived value is < 0x20) and zeroes [a0+0x00..0x17]. On the derived-size failure path it calls the fatal thunk at data slot 0xF9A8C78 with four null arguments and does not return (int3). [V: every instruction in [0x6ae330, 0x6ae404) is accounted for in the reversed source below].
