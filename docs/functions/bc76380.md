## Analyst sections

### Purpose

sub 0xbc76380 is the D3D12 submit RTX override on the bgfx frame path. It reads the record slot pointer, runs the submit acceptance helper (bounded find-char of the argument character within the slot string, accepted at offset <= 2), on acceptance copies the first diff bytes of {ptr,len} to a 4-byte stack dest, calls the function pointer stored at data_f9a90c8 with that dest (result becomes the return value), and advances the slot by diff + 1. On rejection it returns the flags argument unchanged. Every draw of the game goes through this function or one of its parents (0xbc5f7b0) [V].
