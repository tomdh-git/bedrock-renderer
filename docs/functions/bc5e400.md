## Signature guess and register map
x64 Microsoft ABI, `__cdecl`-equivalent free function in namespace `native`. The prologue saves no frame pointer; `rcx` (self) is copied to `rsi` at entry and all struct fields are read through `rsi`. `r8` holds the element to insert and is consumed before being overwritten. `r9` at entry is never read. Return value in `rax` = iterator (Elem*) to the inserted element.

```
Elem* sub_bc5e400(Bc5e400Array* self /*rcx->rsi*/, Bc5e400Elem* position /*rdx*/,
                  const Bc5e400Elem* element /*r8*/);
```

Register map at entry: rcx=self, rdx=position, r8=element. Inside: rsi=self, r14=begin, r13=end/count1, r12=element/src, r15=position/dst cursor, rdi=newcap/newcap_bytes, rbx=allocated buffer/insert-slot base.

`0xbc5e570..0xbc5e5ab`: loop B setup: rcx = end; if (position == end) goto 0xbc5e600; rax = insert slot; dst = insert slot + 1; src = position.
`0xbc5e5ac..0xbc5e5bc`: loop B copies [position, end): per element zero, strong +1, copy, advance; until src == end.

`0xbc5e600..0xbc5e632`: destroy old elements [begin, end): if (begin == 0) skip; per element object = old->field1; lock dec strong; if 0: `0xbc5e643  call qword ptr [0xF99FFA0]` destroy object; lock dec weak; if 0: `0xbc5e65a  call qword ptr [0xF99FFA0]` free control block; advance.
`0xbc5e662..0xbc5e695`: free the old buffer: old_cap_bytes = cap_end - begin; if < 0x1000: rcx = begin; else old_base = [begin - 8], probe = begin - 8 - old_base; if (probe >= 0x20): `0xbc5e6ea  call qword ptr [0xF9A8C78]` with rcx=rdx=r8=r9=0 (dead: noreturn, int3 padding follows); rcx = old_base; `0xbc5e691  call 0xE935700` deallocates the buffer base.
`0xbc5e696..0xbc5e6be`: self->begin = buf; self->end = buf + count1*16; self->cap_end = buf + newcap_bytes; rax = insert slot; epilogue; ret.
`0xbc5e6bf..0xbc5e6d6`: dead failure paths: slow path `0xbc5e6bf  mov rcx,rbx` `0xbc5e6c5  call 0x9BC830` then jmp 0xbc5e4b4; `0xbc5e6d2  call 0x75740` (noreturn).

## Ownership / threading
No synchronization beyond the lock inc/dec on the refcounted objects' strong/weak dwords (same as the original). The function mutates the array in place; callers serialize access to the array (unchanged contract). Reentrant with respect to distinct arrays. The two data slots ([0xF99FFA0], [0xF9A8C78]) are read at call time, exactly as the original's `call qword ptr [slot]` instructions do.
