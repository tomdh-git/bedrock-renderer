# Dossier: sub_87440 (0x87440, size 0xcf, 1.26.62.01)

## Summary
Release a node tree rooted at a release-context pointer (RCX). The context has
child_begin (+0x28), child_end (+0x30), limit (+0x38), and a flag byte (+0x40).
If the flag is non-zero the function returns immediately. Otherwise it releases
each child node (0x40 bytes each) recursively via sub_9c590, then hands the
context block to sub_e935700, clears the three slot fields, and tails to
sub_9c650(a0 + 0x10). A heap-corruption check failure calls the data-slot
function pointer at RVA 0xF9A8C78 with five zero arguments (noreturn block,
ends in int3).
