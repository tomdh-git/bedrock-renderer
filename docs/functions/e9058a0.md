## Ownership / Threading

This function is a destructor/cleanup for a frame renderer lambda object. It releases two shared pointer references and deallocates heap storage if the object used a large allocation (non-SBO). The atomic refcount decrement on shared_ptr1 implies shared ownership across threads. The vendor deleter thunk (0xF99FFA0) is a loader-resolved function pointer, likely from a DLL (vendor class). No locks other than the atomic refcount are used. Safe for concurrent destruction of distinct objects; concurrent destruction of the same object would race on the refcount (standard shared_ptr behavior).
