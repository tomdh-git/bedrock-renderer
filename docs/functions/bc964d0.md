## Analyst sections

### Purpose

sub_0xbc964d0 constructs one frame-graph node object (self): it moves the refcounted object at a1+0x38 into self+0x70 (plain move unless the object references itself, in which case vtable[1](obj, &self->field_0x38) addrefs and vtable[4](obj, &self->field_0x38 | flag) releases), clears a1+0x38, moves string a3 into self+0x78/+0x80 (zeroing a3), then copies string a2 (pointer a2+0x00, size a2+0x08) into a buffer at self+0x88: inline when the signed size is < 0x10, otherwise a behind-header 0x20-aligned heap allocation via the global allocator's vtable[1] (header word = original pointer), size stored at self+0x98 and capacity at self+0xA0. A size field with bit 63 set routes to the boundary stl length error (0x75720, noreturn) followed by int3 padding. Every instruction of [0xbc964d0, 0xbc966b0) is accounted for in the reversed source below. [V]
