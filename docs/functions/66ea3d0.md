## Behavior notes (no RVAs)
The terrain extractor picks a terrain material family from one "pass kind" value carried by the description (end portal, water prepass, chunk prepass / forward / PBR-forward, fog-alpha variants), resolves it through the shared material cache, builds a pass-state descriptor, writes the frame-constant uniforms (mesh context, view position and time, fog distance control, fog colour) into the pass record by finding each uniform in the material's binding list through its name hash, binds terrain info, and then either calls one of three dedicated fog-alpha builders or runs one of four inline loops that turn the chunk draw lists into per-draw items.
