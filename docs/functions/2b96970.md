## Analyst sections

### Purpose

`sub_2b96970` looks up an entry in a 2D object array and, on success, fills an output object with the array object pointer, a data cursor (array+0x30), the handle, and a valid flag. It acquires a reference on the input's refcounted object (lock cmpxchg) and releases it (lock dec + optional destructor/deallocator via data-slot thunk) before returning.

### Ownership / threading

Refcount acquire uses `lock cmpxchg` (release semantics on success). Release uses `lock dec` on +0x8 (refcount) and +0xC (count0xC); when either reaches 0, the corresponding vfptr entry is invoked via the `sub_eea6040` data-slot thunk (destructor at vfptr[0], deallocator at vfptr[1]). No SEH, no null guards beyond the original's own tests.
