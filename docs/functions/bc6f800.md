# Dossier: bgfx destroy-handle enqueue (cmd 0x1D) (0xbc6f800)

## Mechanical facts
- [V] Size 0xbb bytes, 1 block, proven extent, 3 xrefs in (rdis).
- [V] Signature (inferred): `void enqueueDestroyB(Context* ctx /*rcx*/, u16 handle /*dx*/)`.
- [V] Callees: `0xebdbf10`, `0xebce390` x2, `0xebdbf20`.

## Behavior [V]
Same structure as `0xbc6f2a0` but targets a different Frame tail list and opcode:
1. Locks `ctx+0x1C0`.
2. `Frame* f = [ctx+0x1CFD0C8]`.
3. Pushes handle to `f+0xE478AC + (u16[f+0xE498AC]*2)`, increments `u16[f+0xE498AC]`.
4. Emits post-cmd byte `0x1D` + aligned `u16 handle` into cmdPost (`f+0xE05820/0xE05828`).
5. Unlocks.

## A4-A8 relevance
