# Dossier: sampler descriptor builder + cache (0xe820500), 1.26.62.01

Static [V] unless tagged. Header: src/sdk/mc/deps/bgfx/d3d12/SamplerFlags.h (decode + static_asserts). Callers (xref): 0xe818bc0, 0xe821120 (draw executor).

## Signature
`u16 build(SamplerHeap* rcx, const u32* flags rdx, u32 count r8, const float (*border)[4] r9)` returns the heap slot group index (bx), 0xFFFF when the free list is empty.
- count is clamped to 16 (edi = min(count,16)).
- r9 = optional table of 16-byte border colours, indexed by (flags >> 24) & 0xF.

## Phases
1. Key: bgfx `HashMurmur2A` (seed 0) over the first min(count,16)*4 bytes of the flag array: `add` = 0xbc76610, finalisation inline at 0xe820564..0xe8205bf (constants 0x5bd1e995, shifts 24/13/15). Key = r10d (u32).
2. Lookup: open hash map at heap+0x60 (bucket vector begin/end at +0x68/+0x70, bucket index = `(((b0*0x1003f+b1)*0x1003f+b2)*0x1003f+b3) * 0xfc5d1543ec5f01 & (nbuckets-2)` over the signed key bytes, chain `node+0x10 = next`, `node+0x00 = key`, `node+0x08 u16 = slot`). Hit: return node+8 (if it is 0xFFFF fall through to re-create).
3. Miss: take a slot from the u16 free ring at heap+8 (`u16 head +0, u16 count +2, u16 ring +4`; 0xFFFF when exhausted).
4. For each sampler i: fill D3D12_SAMPLER_DESC on the stack (see header) and `ID3D12Device::CreateSampler` (device `[ctx+0x400]`, vtable +0xB0) into the CPU handle `heap[+0x10] + ((u16 heap[+0x24] * slot + i) * u32 heap[+0x20])` (+0x20 = descriptor increment, +0x24 = descriptors per group).
5. Insert {key -> slot} with 0xe805e50 (re-hash 0xe806410 when needed), return slot.

## Field decode [V]
Filter = min[(f>>6)&3] | mag[(f>>8)&3] | mip[bit10] | (cmp nibble != 0 ? 0x80 : 0); AddressU/V/W = {1,2,3,4}[f&3 / (f>>2)&3 / (f>>4)&3]; MipLODBias 0; MaxAnisotropy = `[ctx+0x19FD8]` (read once at 0xe8206ab); Comparison = table[(f>>16)&0xF] or 1; MinLOD 0.
BorderColor: copied from `border[(f>>24)&0xF]` only when border != null and (W==BORDER or U==BORDER or V==BORDER), else zero.
MaxLOD = `f & 0x10000000 ? 3.0 : FLT_MAX` (floats at rva 0xf4ed270).

CONTRADICTS 6ax: bit 28 is NOT the border-colour selector; it selects MaxLOD 3.0 vs FLT_MAX. The border colour comes from the r9 table with the standard bgfx 4-bit index at bits 24..27, gated by the BORDER address mode.
