### Purpose

Turns a texture handle into the loaded texture: used by every description constructor that carries a texture (MeshFallback, Crack, Sky, text, selection overlay). Returns an empty reference until the texture is loaded and ready, so a description built in the first frames of a texture load draws without it. Instruction-complete.

### Reversed source

```cpp
SharedRef resolveTexture(const TextureHandle* h) {          // rcx = out (returned), rdx = h
    const TexSlot* slot = h->ptr;                            // [h]
    if (!slot) return {};
    const TexResource* r = slot->resource;                   // slot +0x18
    if (!r || r->state /*u8 +0x68*/ != 2) return {};          // 2 = loaded
    GpuTexture* t = r->texture;                              // r +0x00
    if (!t) return {};
    _InterlockedIncrement16(&t->touch /*+0x10*/);            // last-use counter
    if (!(t->flags /*u8 +0x12*/ & 1)) return {};             // not ready on the GPU yet
    return SharedRef{ r->texture, r->ctrl /*+0x08, +1 strong*/ };
}
```
