## Draw path, predefined uniforms (0xe82a49e..0xe82bfe9, 62.01) [V dispatch, mapping by what each case reads]

The program record holds up to 28 predefined-uniform slots: `prog + 0x10 + i*8 = { u32 loc; u16 count; u8 type; u8 _ }`, count of used slots = u8 at `prog + 0xF0`.
