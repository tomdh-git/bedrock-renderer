### Purpose

Not a "pass lookup" (the name used in earlier notes): it is a **thread-local object getter**. `this` owns a thread-specific slot (u32 TLS index at this+0xA0), a factory `std::function` at this+0x38 and a list of all instances (this+0x40 / +0x48, guarded by the mutex at this+0x50). The first call on a thread allocates a 0x8C8-byte node (list links + a 0x8B8-byte value), builds the value with the factory, stores it in the thread slot and appends it to the list.
