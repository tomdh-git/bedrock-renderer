## Reversed source
The function samples a sorted key/color ramp for a lookup value x and writes a float4 color to out, returning the out pointer.
The gradient object (self/rcx) holds the ramp range [f0, f8) as begin/end pointers, each record being 0x14 bytes: a float key at +0x0 and a float4 color at +0x4. f18/f1c are wrap bounds.
- Empty ramp (begin == end): out = *(float4*)(r9src), the caller-supplied default color (0x11266af).
- Single record (end - begin == 0x14): out = record 0's color at begin + 4 (0x11266a3).
- Otherwise walk records starting at key_1: for each record with keyHi at r9 and keyLo at r9 - 0x14, keep walking while x < keyLo or keyHi <= x (ucomiss treats unordered as taken, so NaN x walks the whole ramp). On the first keyLo <= x < keyHi, take xmm0 = color[keyLo record], xmm3 = color[keyHi record], xmm1 = keyLo (0x11266ee).
- Walk exhausted (x < keyFirst or x >= keyLast): xmm1 = keyLast, xmm0 = vLast (0x11266fa). If interpolateFlag == 0 ([rsp+0x40]), out = vLast (clamp, 0x112672d). Otherwise xmm4 = keyFirst, xmm3 = vFirst, f18 = [rcx+0x18], f1c = [rcx+0x1c] (0x112670c): if keyLast <= x, top wrap xmm4 = keyFirst + f1c - f18 with xmm1 = keyLast (0x1126735); else bottom wrap xmm1 = keyLast - f1c + f18 with xmm4 = keyFirst (0x1126723).
- At 0x112673d: if xmm4 == xmm1 ordered (equal keys / degenerate interval), out = xmm0 (0x1126744); otherwise t = (x - xmm1) / (xmm4 - xmm1) and out = xmm0*(1-t) + xmm3*t with 1.0f from [0xEEC8060] (0x1126749..0x1126775).
