### 0x34d650..0x34d670 — Main loop (loc_34d650)

```
0x34d650  mov rcx,[rsi+0x10]
0x34d654  call 0x34D640
0x34d659  mov rdi,[rsi]

0x34d661  mov rcx,rsi

0x34d669  cmp byte ptr [rdi+0x19],0

```

Loop body:
1. `cur->p10` (+0x10) loaded into RCX, recursive call to `sub_34d640` (processes first child subtree).
2. `cur->p0` (+0x00) loaded into RDI (sibling pointer).
3. EDX=0x30 set (dead for callee), RCX=`cur`, call `sub_e935700` (processes current node).
4. Test `sibling->b19` (+0x19): if zero, move sibling to RSI (cursor) and loop; otherwise fall through to epilogue.

```

0x34d676  pop rdi
0x34d677  pop rsi
```

Restore stack, callee-saved registers, return.
