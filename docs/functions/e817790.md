## Call targets

- 0xe817813 / 0xe817833 / 0xe81784a: `call qword ptr [0xF99FFA0]`. The slot 0xF99FFA0 holds
  sub_eea6040 (`jmp rax`); rax is set from connection vtable slots 0x120 / 0x48 / 0x10 just
  before. These are guarded virtual calls (slot 36 / slot 9 / slot 2). The slot is loader-filled
  (docs/data/native_boundary.tsv: 0xeea6040 vendor "thunk via data slot 0xF99FFA0"); the vtable
  targets are runtime values. Expressed as the resolved vtable-slot invocation (identical to the
  jmp-rax chain). Not unresolved.
- 0xe817872: `call 0xE951550` = sub_e951550, __security_check_cookie (crt boundary).
