## Analyst sections

### Purpose
The D3D12 backend's batched draw emitter. The draw executor (0xe821120) accumulates pre-built draw records per kind (non-indexed / indexed) in a DrawBatcher; this function flushes one kind: it binds the vertex/index buffer views and the two per-draw constant buffers (only when they differ from the cached ones) and issues the draws, either one by one or as a single ExecuteIndirect. [V static, 6ej] Not yet run in game.
