### Purpose

Builds the D3D12 vertex buffer views for every stream of one draw and computes the draw's vertex count: for each bit of the stream mask it transitions the stream's vertex buffer to GENERIC_READ (once per frame, tracked per handle), looks up the vertex layout stride, and writes `{gpuAddress + startVertex*stride, size - startVertex*stride, stride}`. Returns the number of views written. Called from the executor's indirect and batched draw paths (0xe82c4a2, 0xe82c6ef, 0xe82cb8b) [V]. All 165 instructions are accounted for below.
