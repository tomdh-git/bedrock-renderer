## Role in the traced frame path (M3b / A2)
Group visitor (A2 hop). For each Item variant description: reads the tag byte at desc+8, bounds-checks tag <= 0xA, then jumps through the relative int32 jump table at 0xF2BF2D0 to one of 11 tag blocks. Tag blocks extract per-tag data (mesh names, chunk occluders, vertex-decl elements, batch actors, skinned mesh, ...) and feed the extractors/draw builders downstream. This unit decodes the dispatch and the verified prefix of every tag block; full tag bodies (extractors, sub-call semantics) are [I] bodies and remain M1d/M3b follow-up.
