## Disassembly Phases

### 0x3af4e0..0x3af4f7: Prologue & argument save
Saves non-volatile registers, allocates 0x40 bytes stack, saves all 4 args (RCX,RDX,R8,R9) to RDI,RSI,[rsp+0x70],[rsp+0x78].

### 0x3af4f7..0x3af50b: Stack cookie initialization
Loads `__security_cookie` (global at 0x1230A0C0), XORs with RSP, stores cookie at [rsp+0x38]. Sets RBX = &[rsp+0x70] (pointer to saved arg3/arg4), stores RBX at [rsp+0x30].

### 0x3af510..0x3af515: Call sub_3b23c0, extract first qword
Calls sub_3b23c0 (lift callee, returns pointer to data at 0x128CC490 in RAX), reads first qword of that data into RCX.

### 0x3af518..0x3af533: Shadow space setup & indirect call
Sets up shadow space: [rsp+0x28]=RBX, [rsp+0x20]=0. Prepares args for indirect call: RDX=saved arg1, R8=-1, R9=saved arg2. Calls function pointer at data slot 0xF9A8B30 with (RCX, RDX, R8, R9). Slot documented per indirect-call rule.

### 0x3af539..0x3af554: Stack cookie check & normal return
Reloads cookie from [rsp+0x38], XORs with RSP, compares with global __security_cookie. On match: restores stack, pops non-volatiles, returns indirect call result in RAX.

### 0x3af555..0x3af562: Cookie mismatch failure path
On mismatch: recomputes cookie, calls 0xE951550 (__report_gsfailure, boundary). int3 padding follows (unreachable).
