// arg1 rcx = out   (pointer to a 32-byte string object: [out+0x00] data, [out+0x10] size, [out+0x18] capacity)

## Register / argument map

- `rdx` = pointer to the u16 value (read via `movzx edx,word ptr [rdx]` at 0xe80682c)
- `rsi` = `out` (destination of the final 32-byte copy)
- `rsp+0x40` = `rbp` frame pointer; temporary string object lives at `[rbp-0x20]`:
