## Analyst sections

### Purpose

`sub_5667e70` is a pass-tasks inline-buffer release helper. Given `a0` (RCX):

1. If `byte[a0+0x168] == 1`, calls the boundary/stl helper `sub_655cea0(&a0+0x130)` (return ignored).
2. Releases inline buffer #1 at `[a0+0x118]` (begin) / `[a0+0x128]` (end): if begin != 0, computes `size = end - begin`; if `size < 0x1000` the dealloc argument is `begin`, otherwise reads the heap header at `begin-8`, computes `delta = (begin-8) - [begin-8]`; if `delta >= 0x20` takes the noreturn fail path; otherwise the dealloc argument is the heap header and `size + 0x27` is dead. Calls `sub_e935700(deallocArg)`, then clears `[a0+0x118..0x128)` (16 bytes) and sets `[a0+0x128] = 0`.
3. If `byte[a0+0x100] == 1`, repeats the same sequence for inline buffer #2 at `[a0+0xE8]` / `[a0+0xF8]`.
4. Returns via the standard epilogue.

On heap-header corruption (`delta >= 0x20`) it takes a noreturn fail path: stores 0 to `[rsp+0x20]` (dead), zeroes rcx/rdx/r8/r9, calls `qword ptr [0xF9A8C78]` (data slot) with 4 zero args, then `int3`.
