### Purpose

The loader that ResourceCache::get (0x675e440) calls when a cached resource is missing. It creates the Resource object right away (so the cache has something to return), wraps the LoadRequest in a job and queues the job: directly into the owner thread's pending vector, or into a per-thread vector when called from a worker. Nothing is loaded here. All 0xC69 bytes read. The synchronous twin is 0xbcc0ee0 (it builds the same job on the stack and runs it at once through 0xbcc06a0); its cache caller is the twin cache 0x567c8b0 (same cache layout as 0x675e440).
