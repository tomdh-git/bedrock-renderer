### Purpose

Parses the body of a `RenderDragon.CompiledMaterialDefinition` (material.bin after the header and any decryption, docs/functions/e870350.md) into the Material: name, parent, buffers, uniforms, string properties and passes. For each pass it chooses the best shader per stage for this device. 0x2D7A bytes. Every stream read, every validity check and every container insert is accounted for (filtered listing plus the pass, variant and shader loops read raw). The inner container helpers are not reversed.

### Shader selection (the platform cap) [V]

```cpp
uint8_t deviceMax = currentShaderPlatform();                 // 0xc25a1c0, read once before the passes
uint8_t best[4] = {};                                        // per stage
for (Shader& sh : variant.shaders) {
    if (sh.platform > maxPlatform /*0x0D*/ || sh.platform > deviceMax) continue;
    if (sh.platform < best[sh.stage]) continue;
    best[sh.stage] = sh.platform;  stageSlot[sh.stage] = std::move(sh);   // 0xe876600
}
for (int st = 0; st < 4; ++st)
    if (!stageSlot[st].empty())
        variant.shaders.insert({best[st], st}, stageSlot[st]);            // 0xe878800, then move
```
So a material.bin carries the shaders for every platform, and the loader keeps one per stage: the highest platform that is no higher than 13 and no higher than what the device supports. The 0x0D argument to deserialize is therefore the highest shader platform the build accepts.

After a pass's variants, 0xe87ac30 builds the variant lookup from the pass flag table and the variants (it fails the parse if they do not fit together), then the pass is stored by name.
