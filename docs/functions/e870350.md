### Addendum (6hg): the crypto helpers, resolved [V]

The crypto layer is OpenSSL (strings `crypto\evp\digest.c`, `crypto\objects\obj_dat.c`).

- `hash(out, alg, data, size)` 0xae07e0: hasher from the factory 0xae02f0, `update` (vcall +0x10), digest length (vcall +0x20), `final` into the resized string (vcall +0x18). Factory: alg 0 = built-in MD5 (state 0x67452301 / 0xEFCDAB89 / 0x98BADCFE / 0x10325476); alg 1..4 = OpenSSL digests by NID from the table at rdata 0xF0A5838 = {64 SHA-1, 672 SHA-256, 673 SHA-384, 674 SHA-512} (EVP_MD_CTX_new 0xe974d30, digest lookup 0xe976410 / 0xe976210, EVP_DigestInit_ex 0xe975100). So **alg 2 = SHA-256**.
- `makeCipher(type, mode)` 0xae3210: wrapper (vtable rdata 0xF0A52C0) around a 0x20-byte implementation {vtable 0xF0A5270, u32 type +0x08, u32 mode +0x0C}; its init (slot 1, 0xae29f0) picks the EVP cipher from two 7-entry tables (rdata 0xF0A588C for type 0, 0xF0A5870 for type 1), each getter choosing the AES-NI or software EVP_CIPHER by a CPU feature bit (0x2000000):

| mode | type 0 (AES-128) | type 1 (AES-256) |
|---|---|---|
| 0 | ECB 418 | ECB 426 |
| 1 | CBC 419 | CBC 427 |
| 2 | CFB8 653 | CFB8 655 |
| 3 | CFB 421 | CFB 429 |
| 4 | OFB 420 | OFB 428 |
| 5 | **GCM 895** | **GCM 901** |
| 6 | CTR 904 | CTR 906 |

- 0xad6e90 (0x139 bytes, 67 callers) runs before every factory: the library's lazy one-time initialisation [I: by call pattern].

So material.bin SMPL = **AES-256-GCM** with key = the stored keyHash, which must equal **SHA-256(the base64 key string)**, and the file's IV. KYPR's cipher object is built with the packed constant 0x500000001 (type 1, mode 5): also AES-256-GCM, keyed by SHA-256 of the 86-byte unwrapped secret.
