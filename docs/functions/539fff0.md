### Purpose

Draws the block-breaking crack overlays and prepares next frame's crack meshes. Three phases in one function (all inside 0x539fff0..0x53a0986): (1) when no frame builder is available, draw each crack as a generic mesh; (2) normally, build one small RenderCrackDescription per crack and insert it into Item as tag 5; (3) walk the level renderer's destroy-progress list and rebuild the crack geometry of every block that is being broken. Corrects 6ea, which merged phases 2 and 3.
